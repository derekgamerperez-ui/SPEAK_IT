# 🎙️ SPEAK IT!

**SPEAK IT!** es una aplicación interactiva desarrollada con Python, Flask, HTML y CSS que ayuda a practicar vocabulario en inglés mediante el reconocimiento de voz y respuestas escritas.

El jugador debe traducir palabras del español al inglés. Puede responder pronunciando la palabra para que el sistema reconozca su voz o escribirla directamente si no puede utilizar el micrófono.

### ✨ Características
- 🎤 Reconocimiento de voz en inglés.
- ⌨️ Opción para escribir las respuestas.
- 🎯 Sistema de puntuación.
- 📚 Tres niveles de dificultad: Fácil, Medio y Difícil.
- 🏆 Resultados y clasificación al finalizar la partida.
- 🎨 Interfaz visual interactiva y sencilla.

### 🛠️ Tecnologías utilizadas
- Python
- Flask
- HTML5
- CSS3
- SpeechRecognition
- SoundDevice
- SciPy

### 🎯 Objetivo
Hacer que el aprendizaje y la práctica del vocabulario en inglés sean más dinámicos, accesibles y entretenidos.

**Proyecto educativo desarrollado para practicar programación, integración de bibliotecas y desarrollo web con Python.**
